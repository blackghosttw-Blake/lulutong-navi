# 路路通導航

手機瀏覽器可用的導航網頁 App（PWA）：地圖定位、地點搜尋、路線規劃、語音導航、測速照相提醒、路口／交流道放大圖。

## 使用
用手機瀏覽器開啟網址，允許位置權限，搜尋目的地後按「開始導航」。
也可以按「模擬行駛」在不移動的情況下試跑路線。
Android Chrome 可以「加到主畫面」；iPhone 請用 Safari 的「加入主畫面」。

## 資料來源與致謝
- 地圖：© OpenStreetMap 貢獻者（ODbL）
- 路線規劃：Valhalla（FOSSGIS 公共服務）
- 地點搜尋：Nominatim（OpenStreetMap）
- 測速照相：內政部警政署「測速執法設置點」開放資料（政府資料開放平臺，`cameras.json`）

## 重要限制
- 這是實驗性專案，**不保證路線、限速與測速照相位置的正確性**，請以實際路況與標誌為準。駕駛中請勿操作手機。
- 使用的是免費公共服務（地圖圖磚、路線、搜尋），僅適合個人少量測試，不適合大量使用。
- 路口放大圖是依路線與交流道資料繪製的示意圖，不是實景照片。
- 瀏覽器在螢幕關閉或切到背景時，GPS 與語音可能被系統暫停。
